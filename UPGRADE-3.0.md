# UPGRADE TO 3.0

PageBundle 3.0 is a rewrite built on top of AdminBundle 3.0. There is no
in-place upgrade path from previous versions: treat it as a new installation
and follow [doc/installation.md](doc/installation.md).

## Requirements

* `aropixel/admin-bundle` ^3.0 (see its
  [UPGRADE-3.0.md](https://github.com/aropixel/admin-bundle/blob/main/UPGRADE-3.0.md)
  for the platform requirements: Symfony 6.4/7.x/8.x, Doctrine ORM 2 or 3,
  Stimulus through AssetMapper)
